# ByteSpace v1.0.0

**Release date:** 2026-09-30

The first stable release of ByteSpace, a responsive online learning platform for discovering courses, learning from expert creators, and tracking progress.

## Highlights

- Browse a curated course catalog with search, category and difficulty filters, sorting, and pagination.
- Explore course overview, lesson, and review pages, with enrollment, progress tracking, and review filtering.
- View creator profiles and persist follow preferences across sessions.
- Use sign-in and registration pages with client-side form validation and demo feedback.
- Navigate an accessible, responsive interface with mobile navigation, loading skeletons, and error and not-found pages.
- Persist enrollment, creator follow, and newsletter preferences in browser local storage.
- Run the included Playwright functionality, responsive layout, and visual regression suites.

## Notes

- This release uses local seed data and browser storage; authentication and enrollment are demo flows and do not connect to a backend.
- The application is built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.
